# Dashmix admin integration

This directory contains the Reggaeton El Real backend integration layer based on layout patterns from the licensed Dashmix 5.12.0 package purchased for this end product.

Phase 1 intentionally contains only backend UI infrastructure. It is not loaded by the public storefront and does not include Dashmix demo pages or the plugin catalog.

Plugins will be added individually in later phases only when they are integrated into an actual administrative module.
